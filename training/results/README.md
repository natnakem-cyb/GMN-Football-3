# GMN-Football-3 Training Results & Benchmarks

This directory contains persistent evaluation metrics, training trend traces, and algorithm comparison tables for reinforcement learning models trained on GMN-Football-3.

## Output Files

1. **`win_rate_progress.csv`**
   - Canonical CSV recording checkpoint-by-checkpoint evaluation outcomes at every 100k-step milestone (and final checkpoints).
   - **Schema**:
     `scenario,algorithm,step,learning_rate,goal_rate_pct,mean_reward,std_reward,shots_per_ep,turnover_rate,episodes,deterministic,checkpoint_path`
   - **Goal-Rate ("Win-Rate") Definition**: Percentage of evaluation episodes where the attacking (left) team scores $\ge 1$ goal under deterministic rollouts across a fixed seed set.

2. **`trend_<algorithm>_<scenario>.csv`**
   - In-training rolling performance progression logs captured at periodic update intervals during training.
   - **Schema**: `step,episodes,mean_reward,goal_rate_pct`

3. **`comparison_table.md` & `comparison_table.html`**
   - Multi-algorithm progression tables generated by `training/generate_comparison_table.py`.
   - Formats evaluation checkpoints across 100k, 200k, ..., 1M step increments, comparing MAPPO vs. IPPO / PPO win-rates and learning rates across scenarios.
